# 小米运动健康数据查看器

扫码登录小米账号，直接查看本人小米运动健康云端的最新日报和历史日报。一个 Python 脚本，可在本机或青龙容器里手动运行。

**先理解“最新”**：脚本读取已经上传到小米云的数据。它不能直接连接手环，也不能替手机 App 触发同步。想更新数据，先打开手机上的小米运动健康 App 完成同步，再运行脚本。

```text
手环 / 手机 → 小米运动健康 App → 小米云 → Python 脚本 → 终端显示
```

## 能做什么

- 查看近 7 天内各指标最近一条日报，显示数据所属日期。
- 按结束日期查询 1～31 天的历史日报。
- 查询步数、距离、热量、心率、睡眠、血氧；实际返回哪些指标取决于云端记录。
- 默认输出中文摘要，加 `--json` 输出结构化结果。
- 首次登录保存本机凭据；后续查询复用凭据，SDK 可尝试自动续期。

程序不连接 SQLite，不创建定时任务，不发送通知，也不启动网页服务。

## 5 分钟开始

需要 **Python 3.11+**，并且手机小米运动健康 App 已登录、同步过数据。这里使用的是小米运动健康（Mi Fitness），不能把 Zepp Life 的账号链路直接当成同一个接口。

下面的 `python3` 必须是 3.11 或更新版本。如果电脑安装了多个 Python，请在所有命令中使用同一个解释器，例如 `python3.12`。

```bash
git clone https://github.com/xiangmingya/xiaomi-health-viewer.git
cd xiaomi-health-viewer
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python xiaomi_health.py login --probe
```

最后一条命令会打印二维码图片链接和备用小米账号登录链接。扫码或在手机打开备用链接，按小米页面提示确认。最长等待约 5 分钟。登录成功后会自动试读一次最新日报。

**密码、验证码都在小米官方页面中输入，不需要填进本项目。**默认登录凭据保存到脚本旁的 `private/token.json`，不要上传这个目录。

登录后直接查询：

```bash
# 各指标近 7 天内最近一条日报
python xiaomi_health.py latest

# 查询 2026-10-05 至 2026-10-11，包含首尾日期
python xiaomi_health.py history --date 2026-10-11 --days 7

# 查看完整结构
python xiaomi_health.py latest --json
```

## 在青龙里使用

青龙容器内同样需要 Python 3.11+。安装依赖，把脚本放到脚本目录，先在容器终端执行一次 `login --probe`。之后在终端手动运行 `latest` 或 `history` 即可，不必建立定时任务。完整操作见[运行说明](docs/运行说明.md#在青龙中手动运行)。

## 实测情况

2026-10-12 使用真实国区账号验证：扫码登录成功；本人步数日报成功返回步数、距离和热量；最新日报查看、指定日期历史查看均成功。测试账号的近期心率、睡眠、血氧未返回记录，但能查到更早的睡眠记录，因此不将近期空结果视为接口不支持该指标。

这不是小米官方开放 API。依赖固定为 `mi-fitness==0.2.0`；本人日报接口名称、请求参数、返回结构可能随服务端变化。程序使用 SDK 的内部请求方法，升级依赖前应重新验证。
