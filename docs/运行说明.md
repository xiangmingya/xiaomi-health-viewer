# 运行说明

## 运行前准备

1. 手机安装小米运动健康 App，登录与目标健康数据对应的小米账号。
2. 打开 App，完成一次手环/手机数据同步。
3. 准备可访问小米官方账号和健康服务的网络。
4. 确认运行脚本的 Python 至少是 3.11。本项目测试使用 Python 3.12。

手环型号不是脚本入参，不需要向开发者提供手机号、密码、验证码、UID 或 token。登录完成后，脚本从本机凭据中读取当前账号 UID。

## 本机安装

下面适用于 macOS / Linux。使用虚拟环境可以让本项目的依赖和其他项目分开。

```bash
git clone https://github.com/xiangmingya/xiaomi-health-viewer.git
cd xiaomi-health-viewer
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

若 `python3 --version` 小于 3.11，先安装新版本，然后从创建虚拟环境这一步开始使用新解释器。不要用一个 Python 安装依赖，再用另一个 Python 运行脚本。

## 第一次登录

```bash
python xiaomi_health.py login --probe
```

终端会打印两个链接：

- **二维码图片链接**：打开后显示小米生成的二维码；使用手机支持小米账号登录的扫码入口扫描并确认。
- **备用登录链接**：没有合适的扫码入口时，在手机浏览器打开，按小米页面提示登录和确认。

二维码最长等待约 5 分钟。确认前请保持这条命令运行。超时后重新运行即可。

看到“登录成功，凭据已保存到本地私有文件”代表凭据已保存。`--probe` 会继续进行一次数据查询，所以“登录成功”与“查询成功”是两个步骤：查询遇到网络错误，不代表必须重新扫码。

只登录，不立即查询：

```bash
python xiaomi_health.py login
```

## 日常查看

```bash
# 查询各指标近 7 天内最近一条日报
python xiaomi_health.py latest

# 查询今天的日报，今天按北京时间计算
python xiaomi_health.py history

# 查询某一天
python xiaomi_health.py history --date 2026-10-11

# 查询以 10 月 11 日为结束日的最近 7 天
python xiaomi_health.py history --date 2026-10-11 --days 7

# 输出完整 JSON
python xiaomi_health.py history --date 2026-10-11 --days 7 --json

# 查看所有参数
python xiaomi_health.py --help
```

`latest` 固定检索 7 天，`--days` 只控制 `history`。所有数据输出都标明数据日期；“查询时间”只是脚本运行时间，不能当作手环测量时间或上传时间。

更长历史可以分成多个不重叠的日期窗口查询，每个窗口最多 31 天。如果服务器返回仍有分页，脚本会提示失败，请进一步缩小窗口；当前版本不会自动遍历分页。

## token 文件的位置

默认位置与当前终端工作目录无关，是 **脚本所在目录 / private / token.json**。

路径优先级：`--token` 参数 > `MI_TOKEN_FILE` 环境变量 > 默认路径。

```bash
# 同一个自定义路径要同时用于登录和后续查询
python xiaomi_health.py login --token ./private/my_token.json
python xiaomi_health.py latest --token ./private/my_token.json

# 也可设置环境变量
export MI_TOKEN_FILE="$PWD/private/my_token.json"
python xiaomi_health.py latest
```

脚本以权限 `600` 保存凭据文件。`private/`、token 文件及本地日志已列入 `.gitignore`。登录二维码和备用链接也是临时登录材料，不要把它们贴进公开 issue。

## 在青龙中手动运行

### 1. 检查容器内 Python

进入青龙容器终端，执行：

```bash
python3 --version
```

结果必须是 3.11+。检查的是容器内部，不是宿主机。旧容器应先准备合适的 Python；本脚本不会为你升级青龙或系统 Python。

### 2. 安装依赖与放置脚本

在青龙的 Python 依赖管理中安装 `mi-fitness==0.2.0`；也可以在实际运行脚本的容器终端使用同一个 Python 安装：

```bash
python3 -m pip install mi-fitness==0.2.0
```

将 `xiaomi_health.py` 放到青龙脚本目录。下例假设放在 `/ql/scripts/xiaomi-health-viewer/`，请根据自己的实际目录调整。

### 3. 首次登录

```bash
cd /ql/scripts/xiaomi-health-viewer
python3 xiaomi_health.py login --probe
```

在手机完成登录，终端保持运行。默认 token 会写到 `/ql/scripts/xiaomi-health-viewer/private/token.json`。确保该目录位于青龙持久化挂载内，且执行用户可写，避免容器重建后丢失登录凭据。

### 4. 手动查询

```bash
python3 /ql/scripts/xiaomi-health-viewer/xiaomi_health.py latest
python3 /ql/scripts/xiaomi-health-viewer/xiaomi_health.py history --date 2026-10-11 --days 7
```

以上命令可以直接在容器终端运行。也可以使用青龙已有的手动执行能力，使用相同的完整命令、同一个 Python 和 token 路径。首次登录需要交互确认，建议在终端完成。

容器日志会保存脚本输出；若输出健康数据，请按自己的需求管理日志访问和保留时间。

## 常见问题

| 现象 | 处理 |
|---|---|
| `缺少依赖` / 找不到 `mi_fitness` | 用运行脚本的解释器执行 `python -m pip install -r requirements.txt` |
| Python 3.10 安装失败 | 使用 Python 3.11+ |
| `尚未登录` | 先运行 `login`，检查登录和查询是否用了同一个 `--token` 路径 |
| 二维码超时 | 重新运行 `login`，在有效时间内确认 |
| `TimeoutError` / `ConnectTimeout` | 检查网络和代理，稍后手动重试；每项查询最多等待 45 秒 |
| 自动刷新失败 | 重新扫码登录；不必将旧凭据内容发给任何人 |
| 指标显示未返回数据 | 确认账号、手机 App 同步和日期；近期无记录不代表历史也没有 |
| 日报分页未读完 | 缩小 `--days`；当前版本不自动翻页 |
| 今天查不到、昨天有数据 | 先在手机 App 同步后重查；脚本不能触发手机上传 |
| `[::1]` 代理环境格式异常 | 脚本会在本进程修正 `NO_PROXY/no_proxy` 的这个条目，不修改系统环境 |

中文摘要只显示错误类型；需要业务码时，加 `--json` 查看指标下的 `status_code/code`。空数据请求成功时退出码为 0，有任何指标请求失败时为 1。
